# Sources of Test Material

Catalogs, PDFs and HTML that evals, smoke runs and exploration use but the repo does not ship. They live in gitignored directories (`catalogs/*.json`, `.test-output/`), so this file is the only record of where they came from. Trimmed excerpts that are shipped (`pkg/oscal/testdata/tree/`) are documented in [that directory's README](../../pkg/oscal/testdata/tree/README.md); it holds their per-excerpt detail and URLs, which are not repeated here.

All rows were verified on 2026-11-11 by downloading the listed URL into an empty scratch directory and comparing SHA-256 with the local copy. The SHA-256 column is of the copy used by the runs. "Retrieved" is when the local copy was fetched: for `sweep/` the time in `sweep/FETCHED_AT`, otherwise the file's mtime (labelled `mtime`). "Version" is the catalog's `metadata.version` unless the row says otherwise.

GitHub URLs are pinned to the commit that last changed the file as of 2026-11-11 (`raw.githubusercontent.com/<repo>/<commit>/<path>`); each pinned URL was downloaded and its SHA-256 matches the recorded one. No row needed to fall back to `main`.

"Why not shipped": none of these documents is a trimmed fixture; the entry gives the file size and the licence of the hosting repository as reported by the GitHub API on 2026-11-11, or "licence not checked". The licence is that of the repository, not a statement about the document, and no redistribution decision was made from it.

## Adding a source

When you download material for a test, eval or smoke run, add its row here in the same change: canonical URL (a release or tag URL where the publisher has one, else a commit-pinned URL), version, retrieval date, SHA-256 of the file as used, why it is not shipped, and licence if you checked it. Verify the URL by re-downloading into an empty directory and comparing hashes. Keep the material out of git unless its licence permits redistribution and it is a trimmed fixture; trimmed fixtures go under `testdata/` with their origin recorded as in the [tree fixtures README](../../pkg/oscal/testdata/tree/README.md).
